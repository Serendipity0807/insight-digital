## 技术栈

- Spring Boot 3.3.x · Spring Cloud 2023.0.x · Spring Cloud Alibaba 2023.0.3.x · JDK 21
- MyBatis-Plus · MySQL 8 · Redis 7 · RocketMQ 5 · Elasticsearch 8 · Nacos 2
- Vue 3(前端)· Python + LangChain + LangGraph(Agent)

- `common/` 通用模块
- `deploy/` 中间件部署
- `frontend/` Vue 前端
